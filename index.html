Atualizar dados do cronograma

Selecione uma versão mais recente da planilha Compras BD.xlsx para atualizar o cronograma direto aqui, sem precisar pedir uma nova geração. O processamento acontece só neste navegador — o arquivo não é enviado para nenhum servidor.

Importante: essa importação de planilha só vale enquanto esta página estiver aberta neste navegador — ao fechar ou recarregar, a lista de cargas volta para os dados com que o arquivo foi gerado. Os status já salvos (Recebido / Não compareceu / Reagendado) não se perdem — eles ficam gravados no servidor e são reaplicados automaticamente às cargas correspondentes depois da importação.

Fonte de dados: aba "Retorno Email" da planilha Compras BD (nível carga/fornecedor). Departamentos de acordo com o depara da aba "Dados". O cronograma é sincronizado automaticamente todo dia a partir da planilha de rede — não precisa mais gerar ou importar nada manualmente para mantê-lo atualizado. O status de cada carga (Recebido / Não compareceu / Reagendado) é salvo automaticamente e fica visível para qualquer pessoa que abrir esta página, em qualquer computador. O botão "Baixar confirmações" continua disponível como backup manual, caso precise enviar um retrato do que mudou nesta sessão.
